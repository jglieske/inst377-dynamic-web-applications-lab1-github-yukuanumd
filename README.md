# Lab 1 – Getting Comfortable with GitHub

Welcome to INST377! This first lab isn't about writing code — it's about
getting comfortable with the basic GitHub workflow you'll use all semester:
**edit → commit → push**.

## What you'll do

1. **Accept this assignment** using the link posted in ELMS/Canvas.
   This creates your own personal copy of this repository.

2. **Open your repository** in one of two ways:
   - **Option A (browser only):** Click on `README.md` in your repo, then
     click the pencil (✏️) icon in the top right to edit it directly on
     GitHub.
   - **Option B (recommended — VS Code):**
     1. Install [VS Code](https://code.visualstudio.com/) if you haven't
        already.
     2. Click the green **Code** button on your repo page and copy the URL.
     3. In VS Code, open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`)
        and run **Git: Clone**, then paste the URL and choose a folder to
        save it in.
     4. Open the cloned folder in VS Code.

3. **Edit this README.md file.** Below, in the "Your Info" section, replace
   the placeholders with your own information.

4. **Save the file.**

5. **Commit your change:**
   - In VS Code: open the **Source Control** panel (left sidebar), you
     should see `README.md` listed as changed. Type a short commit message
     (e.g. `"Add my info"`) and click the checkmark (✓) to commit.
   - On GitHub directly: scroll down after editing and click
     **Commit changes**.

6. **Push your change to GitHub** (VS Code only — GitHub's web editor does
   this automatically):
   - Click **Sync Changes** (or **Push**) in the Source Control panel.
   - VS Code may open a browser window asking you to sign in and authorize
     — this is normal the first time.

7. **Verify it worked:** refresh your repository page on GitHub.com and
   confirm your updated README.md is showing there.

That's it — you've completed your first GitHub commit! 🎉

## Troubleshooting

- **VS Code asks for a username/password when pushing:** Don't type your
  GitHub password — instead, let VS Code open the browser sign-in flow, or
  set up a Personal Access Token if prompted.
- **"Permission denied" or "repository not found":** Make sure you cloned
  *your own* repo (the one under your username), not the original template.
- **Not sure if your push worked?** Check your repo on GitHub.com — if your
  changes show up there, you're done.
- **Still stuck?** Post in the course discussion board or come to office
  hours — this is exactly what Lab 1 is for.
